## [0.1.0] - 2026-11-17

- Native macOS menu bar app powered by your existing GitHub CLI login.
- Relevant, Yours, and Watching views with filtering and keyboard navigation.
- PR counts and unread activity signals, with separate review and CI statuses.
- Connected, collapsible groups for linear pull request stacks.
- Distinct repository and author badges, with prominent @me labels.
- Persistent state-change times, adaptive panel height, and optional notifications.
- Packaged apps for Apple Silicon and Intel, plus installation through crates.io.
